Escape a string for inclusion in JSON string literals.

Produces a JSON-safe string by escaping quotes, backslashes and control characters. The result is suitable to be written inside double quotes.

std::optional< std::string > dagir::render_json_detail::try_emit_primitive ( const std::string_view  s)
inline

Attempt to interpret a string as a JSON primitive.

If s is exactly null, true, false, an integer, or a floating point literal, this returns a string containing the literal representation (without surrounding quotes). Otherwise returns std::nullopt indicating the value should be emitted as a JSON string.
