Detailed Description

Render an IR graph (BDD) as an equivalent boolean expression.

Produces a textual boolean expression using the keywords NOT, AND, and OR. Parentheses are added where necessary to preserve operator precedence (NOT > AND > OR). The implementation expects the input ir_graph to represent a BDD produced by the provided TeDDy/CUDD policies: non-terminal nodes carry a label attribute with the variable name and outgoing edges are labelled with style == "solid" for the true branch and "dashed" for the false branch.
