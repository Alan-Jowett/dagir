Detailed Description

Read-only DAG view adapter for CUDD BDD nodes.

Non-owning adapter that exposes CUDD diagrams via the dagir::concepts::read_only_dag_view concept. The caller must ensure the underlying DdManager and node pointers remain valid for the lifetime of this view.
